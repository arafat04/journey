2. What is an event?

   Ans: An **event** $A$ is a subset of the sample space that answers a particular question. For instance, for a fair coin toss, the sample space is

$$
S = \{H, T\}.
$$

If we define the event

$$
A = \{H\},
$$

then the event occurs when the outcome is a head. In this case, the event contains a single outcome.

Since every subset of the sample space is an event, a sample space with $n$ outcomes has $2^n$ possible events.
